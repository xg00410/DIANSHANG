# 森晖 · 东方美学

以天然水晶与珍珠为主题的多页面品牌展示网站。暖白、墨绿与自然光影构成视觉基调，内容围绕品牌、系列作品、甄选与咨询展开。

## 本地查看

直接打开 `dist/index.html` 即可浏览。需要完整的剪贴板体验时，通过本地 HTTP 服务打开，例如安装 Node.js 后运行：

```sh
node scripts/serve.mjs
```

浏览器访问 http://127.0.0.1:4173 。停止服务按 Ctrl+C。

## 内容结构

- 首页与品牌故事
- 作品目录：分类筛选与搜索
- 腕间春水、月白、山隐：三个独立系列详情
- 定制与礼赠：日常选配、个性组合、礼赠、合作需求
- 甄选之道
- 森晖手记及三篇文章
- 佩戴与保养
- 专属咨询与常见问题

所有页面均适配手机与桌面。导航和正文在构建时输出为完整 HTML，基础浏览不依赖 JavaScript。

## 修改内容

- 页面正文与导航：`scripts/build.mjs`；修改后运行 `node scripts/build.mjs`。
- 视觉样式：`dist/style.css`。
- 筛选、搜索、移动导航、咨询清单：`dist/app.js`。
- 联系方式：`dist/site-config.js`。配置真实微信、电话、邮箱与二维码路径后，咨询页面会显示对应渠道。
- 图片：`dist/assets/`，使用相对路径，支持 GitHub Pages 项目子目录。

`dist` 是完整可部署站点，无需 npm 安装。构建脚本只依赖 Node.js 标准库。

## 检查

```sh
node scripts/build.mjs
node scripts/check.mjs
```

检查会验证所有本地页面链接与资源存在、14 个页面标题及基本页面结构、脚本语法。

## 上传 GitHub 与部署

1. 新建或选择自己的仓库，把项目文件上传至仓库根目录。
2. 如仅需源码保存，到此即可。
3. 如需 GitHub Pages：仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
4. 项目自带 `.github/workflows/pages.yml`，推送默认 `main` 分支后会检查并部署 `dist`。也可手动触发 workflow。

若默认分支不是 main，请修改工作流中的 branches。发布 Pages 意味着对外公开展示，是否启用由仓库所有者决定。

## 正式使用前

- 图片为 AI 生成的品牌与商品概念示意；网页中已注明。不能作为实际商品照片或鉴定证明。
- 品牌名称、所在地、理念来自提供的品牌资料；系列补充名、文章与业务咨询方向为网站编辑内容。
- 是否承接定制、团体礼赠，实际价格、库存、材质、证书、交付与售后条款，均需店铺确认。
- 咨询功能只在浏览器本地生成文字，可复制；没有发送消息、收款、订单或个人信息后台。
- 联系方式尚未配置。没有伪造电话、微信、客户评价、销售数据或制作历史。

详见 `docs/content-and-assets.md`。
